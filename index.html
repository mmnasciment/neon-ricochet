⚠️ CONEXÃO DIRETA P2P BLOQUEADA
Não foi possível abrir o túnel UDP direto entre os dois computadores.
  1. Navegador Brave ou Opera GX (VPN/Escudo): Se um dos dois usar Brave, desative o escudo (leão na barra de endereço) nesta página; no Opera GX ou extensões de privacidade, desative VPN e bloqueadores de WebRTC.
  2. Perfil de Rede no Windows: Se estiverem no mesmo Wi-Fi/roteador, confirme nas configurações do Windows se a rede está como Rede Privada (redes Públicas bloqueiam portas UDP diretas).
  3. Isolamento mDNS Local (Chrome / Edge): Na mesma rede local, se o roteador filtrar mDNS, abra chrome://flags/#enable-webrtc-hide-local-ips-with-mdns nos dois PCs, mude para Disabled e reinicie o navegador.
  4. CGNAT Simétrico Estrito / Rede Corporativa: Algumas redes empresariais, 4G ou provedores com NAT Simétrico bloqueiam portas UDP diretas sem servidor intermediário.
